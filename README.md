# 🌐 Full-Stack Portfolio

This is a Fullstack portfolio that I am creating during my **Full Stack Software Development Bootcamp** at **Circuit Stream**.

## 🚀 Technologies Used
- HTML  
- CSS  
- JavaScript  

## 📖 Background
This is one of the projects I am working on as part of my participation in the **Full Stack Software Development Bootcamp**.  

It is a fun way to showcase the skills I have developed through UBC engineering design courses, bootcamps, design teams, and internships. I am also gaining experience in web development while building this website, and leveraging GitHub Copilot to assist with both advanced and simple additions.

## 📂 Sections
There are currently 5 different sections/webpages in the website:

- **Home**: Short introduction about myself and a link to the projects webpage, also accessible via the navbar.  
- **Projects**: Two sections => Manufacturing Engineering and Software Development, each showing projects from those areas.  
- **About**: A little more about me outside work/studies, including hobbies and adventures.  
- **Contact Me**: My information so you can reach out.  
- **Fun Stuff**: A playful section where I incorporated JavaScript to create a few games.
